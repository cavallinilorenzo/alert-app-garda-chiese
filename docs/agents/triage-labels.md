# Triage Labels

Five canonical labels guide the triage workflow:

| Label | Role | Meaning |
|-------|------|---------|
| `needs-triage` | **Needs triage** | New issue awaiting initial review and categorization. |
| `needs-info` | **Needs info** | Issue awaiting more details from the reporter before work can begin. |
| `ready-for-agent` | **Ready for agent** | Issue is well-defined and ready for an AI agent (or human) to work on. |
| `ready-for-human` | **Ready for human** | Issue has been reviewed/worked on and is ready for human decision or final implementation. |
| `wontfix` | **Wontfix** | Issue has been reviewed and deliberately closed without resolution. |

These labels are used by the `triage` skill to route issues through the workflow.
